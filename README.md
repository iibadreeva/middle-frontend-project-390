# Flight Booking Frontend

[![Actions Status](https://github.com/iibadreeva/middle-frontend-project-390/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/iibadreeva/middle-frontend-project-390/actions)

Современное клиентское приложение для поиска и бронирования авиабилетов. Построено на стеке **React + Vite + TypeScript** с использованием методологии Feature-Sliced Design (FSD).

---

## 🚀 Быстрый старт

Для запуска приложения локально выполните следующие шаги:

1. **Установка зависимостей:**
   ```bash
   make install
   ```

2. **Запуск API-сервера:**
   Приложение работает с реальным сервером `@hexlet/frontend-flight-booking-server` (порт 8080).
   ```bash
   npx frontend-flight-booking-server start
   ```

3. **Запуск в режиме разработки:**
   ```bash
   make dev
   ```
   Приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173). Все запросы к `/api` проксируются на сервер.

### Сборка для продакшена
Если нужно проверить работу SPA в связке с API на одном источнике (как в деплое):
```bash
make build
make start
```
Приложение откроется на [http://localhost:8080](http://localhost:8080).

## 🏗️ Архитектура проекта (`src/`)

Мы используем **feature-based** подход с жёсткими границами между слоями. За соблюдением правил следит ESLint.

- **`app/`** — инициализация приложения: роутер (`routes.ts`), глобальные стили и композиционные страницы.
- **`features/`** — изолированные части функциональности (например, поиск или оформление брони). Каждая фича имеет свою логику и UI. Взаимодействие только через публичный интерфейс (`index.ts`).
- **`shared/`** — переиспользуемые компоненты, хуки, библиотеки, API-клиент и типы.

**Ключевые правила:**
- Фичи не зависят друг от друга.
- `shared` не знает о существовании фич или слоя `app`.
- Доступ к фичам разрешен только через алиас `@features/<name>`.

## ✨ Функциональные возможности

### 🔍 Поиск рейсов
- Интерактивная форма поиска (откуда, куда, дата, количество пассажиров).
- Автоматическая подстановка городов и обработка ошибок загрузки (`FALLBACK_CITIES`).
- Отображение времени в формате **местного времени аэропорта** с учетом часовых поясов.
- Динамический расчет стоимости в зависимости от количества пассажиров.

### 📝 Оформление брони
- Пошаговое заполнение данных пассажиров (до 9 человек).
- Валидация данных в реальном времени (React Hook Form + Zod).
- Контроль наличия свободных мест.
- Уникальный код бронирования после успешной регистрации.

### 📂 Управление бронированием
- Поиск существующей брони по коду и фамилии.
- Просмотр деталей рейса и текущего статуса (`confirmed` / `cancelled`).
- Возможность отмены бронирования.

## 🧪 Тестирование

Проект покрыт различными типами тестов для обеспечения стабильности.

| Тип теста | Команда | Описание |
| :--- | :--- | :--- |
| **Unit & Browser** | `make test` | Запуск всех тестов (Vitest + Playwright) |
| **Playwright UI** | `npx playwright show-report` | Просмотр отчетов о браузерных тестах |

*Перед запуском тестов `make test` убедитесь, что выполнена сборка `make build` и запущен сервер `make start`.*
